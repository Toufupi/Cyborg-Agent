# Cyborg-Agent
This is our latest agent concept implementation, which we call the Cyber Agent. In our new concept, the agent will proactively write general-purpose script programs and save these scripts for subsequent use. In other words, the agent stores knowledge in code. The advantages of this are obvious: the execution results of the code are more reliable and can accurately perform tasks. When facing changing tasks, the code can be adapted to new tasks through version control and rapid iteration. In this way, our agent becomes a code scheduler, just like a cybernetic being—half human, half machine. The reason we are so fascinated by this model also includes the possibility of personal local deployment of agents. A local agent would only be responsible for automatically invoking existing code tools to complete tasks, and if coding tasks arise, they would be handled by online large models. In this way, the knowledge of large-parameter models is preserved in the form of code, which can be executed locally with small models at minimal cost, or even using a locally running LLM backend. To achieve this goal, we also designed the A2C2A protocol to standardize the input and output of the coding part. We hope that this can truly allow agents to integrate into every workflow!
